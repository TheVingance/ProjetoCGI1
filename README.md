# Projeto de Computação Gráfica

Sistema Gráfico 2D interativo desenvolvido em C++ Builder (VCL) para a disciplina de Computação Gráfica.

## Autor
* **TheVingance**

## Estrutura de Branches
* `main`: Versão para acompanhamento das aulas (rasterização, transformações 2D, reflexão e recorte Cohen-Sutherland).
* `completo`: Versão com curvas paramétricas e splines (Casteljau, Hermite, Bézier, B-Spline, Diferenças Progressivas).
